# Наслух

Веб-срез распознавания и озвучки русской речи **на устройстве**. Звук и текст не отправляются на сервер: модели считаются в браузере через WebAssembly.

Это демонстрация принципа, а не магазинная сборка iOS и Android. В браузере стоят более лёгкие модели того же класса. На телефоне их заменяют на GigaAM v3 и тот же Piper, через рантайм [sherpa-onnx](https://k2-fsa.github.io/sherpa/onnx/).

## Запуск

```bash
npm install
npm run dev
```

`predev` копирует wasm-файлы Piper и ONNX Runtime из `node_modules` в `public/`. Эти файлы в git не входят.

Откройте [http://127.0.0.1:43127](http://127.0.0.1:43127).

Первое нажатие «Произнести» скачивает голос Piper `ru_RU-irina-medium`, около 63 МБ. Первое распознавание скачивает квантованный Whisper base, около 80 МБ. Дальше файлы берутся из кэша браузера и работают без сети.

Страница отдаётся с заголовками `Cross-Origin-Opener-Policy: same-origin` и `Cross-Origin-Embedder-Policy: credentialless`. Без них браузер не запускает потоковый WebAssembly, и модели не стартуют.

## Что на экране

- **Слушать** — запись с микрофона или звуковой файл, расшифровка Whisper base.
- **Говорить** — озвучка текста голосом Ирины. Кнопка «Распознать этот звук» прогоняет синтез обратно через распознавание, микрофон для проверки не нужен.

Whisper base слабее на русском, чем GigaAM v3. Это ограничение демо, а не потолок стека.

## Как собирать iOS, Android и веб

Языковую модель в аудиотракт не ставить. Она тяжелее, медленнее и на том же объёме памяти хуже специализированного распознавания. Небольшая LLM уместна позже, уже над готовым текстом: команды, краткое содержание.

| Слой | Выбор |
| --- | --- |
| Распознавание | GigaAM v3 e2e RNN-T, int8, около 216 МБ, через sherpa-onnx. Пунктуация есть в самой модели. Длинное аудио резать VAD на куски до 30 секунд. |
| Озвучка | Piper `ru_RU-irina-medium` или `ruslan`, около 63 МБ, тот же рантайм. |
| Оболочка | React Native. Один интерфейс на iOS и Android, нативный модуль `react-native-sherpa-onnx`. |
| Веб | Тот же контракт движка, реализация на sherpa-onnx WebAssembly и тех же файлах моделей. |
| Не брать | Ionic / Capacitor как основной путь: WebView хуже держит микрофон и считает модель. Два полностью раздельных нативных приложения — только если есть две платформенные команды. |

Модели качать при первом запуске, не зашивать в бинарник магазина: Android Play Asset Delivery, на iOS — загрузка в документы приложения или On-Demand Resources. После загрузки диктовка идёт без сети.

Системные движки Apple Speech и Android SpeechRecognizer можно оставить запасным режимом «без скачивания». Они тоже на устройстве, но качество и голоса различаются между платформами, поэтому одинаковое поведение дают свои модели.
