# @naslukh/speech-core

Контракт офлайн-транскрибации русской речи. Здесь типы задания, возможности среды, манифест модели, миграция базы и нормализатор для WER.

Движков в этом пакете нет. `speech-rn` и `speech-web` появятся отдельными пакетами и будут исполнять тот же контракт. Приложение вызывает `SpeechEngine` и не знает про Opus, SQLite, нарезку и WASM.

Решения, которые ещё не закрыты замером, лежат в [`docs/decisions.md`](../../docs/decisions.md).

## Проверка

Из корня репозитория:

```bash
npm run typecheck:speech-core
npm run test:speech-core
```
