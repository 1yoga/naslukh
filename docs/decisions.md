# Реестр решений

Поля записи: номер, статус, значение, фаза, дата, имя. Строка без имени не закрывает решение. Порог во время прогона не двигают.

Дата ниже — день, когда решение внесено в репозиторий. Открытые строки закроет тот, кто закончит указанную фазу.
